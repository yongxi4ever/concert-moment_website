# Concert Scrapbook · 个人演唱会纪念手帐

一个纯前端、单文件的「个人演唱会纪念网站」，采用手帐 / 剪贴簿（scrapbook）视觉风格，浏览器打开即用，数据保存在本地。

## ✨ 功能特性

### 1. 已看过的演唱会
- 以票根卡片展示：主信息区、虚线撕票线、次要信息行（日期/城市/场馆）、红色图章「已看」。
- 按年份分段的时间线排列，年份用书签标签分隔。
- 支持搜索、排序（时间倒序 / 歌手字母序），可编辑、删除。

### 2. 即将去看的演唱会
- 最近一场以大号撕历倒计时展示，并配复古进度条。
- 其余场次以票根卡片列出，显示「还剩 X 天 X 小时」，图章「将看」。
- 一键「已完成·转已看」，支持编辑、删除。

### 3. 想看的演唱会（愿望清单）
- 便利贴墙形式：软木板背景、图钉、手绘边框、深浅错落的便签。
- 只记录歌手 / 演出名，支持标记完成、转为即将观看、编辑、删除。

### 4. 个人总结看板
- 首页为摊开的手帐：左页目录、右页总结，带书脊阴影与页码。
- 统计已看场次、将看场次、想看数量、已看歌手数，并显示最近一场与最期待一场。

## 🎨 设计风格
- 像素字体 + 天蓝色系手帐配色，纸张质感、硬阴影、胶带、回形针、红色图章等拟物元素。
- 票根设计参考 bigbullui 的 ticket-card 结构。

## 🛠 技术说明
- 纯前端单文件：HTML + CSS + 原生 JavaScript，无框架、无构建步骤。
- 数据持久化：浏览器 localStorage；首次打开载入内置示例数据。
- 字体使用 Google Fonts（需联网）。

## 🚀 部署到 GitHub Pages
1. 上传 index.html 到仓库根目录。
2. Settings → Pages → Source 选择 main 分支 / (root)，保存。
3. 访问 https://用户名.github.io/仓库名/ 即可。
